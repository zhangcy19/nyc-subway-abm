# 首轮正式实验设计

目标：检验LLM群体代理能否在相同正常需求基准上改善站点小时客流预测，并比较zero-shot、few-shot和5/10/20个代理的差异。先完成可复现的历史天气条件实验，不假定LLM一定更好。

## 数据与时间划分

- 现有2023年8–9月纽约地铁数据。按8月覆盖率和客流排名，在Bronx、Brooklyn、Manhattan、Queens各选3站，共12站；不按测试误差选站。
- 8月：建立干天气weekday/hour正常需求，以及few-shot样例。
- 9月1–21日：校正开学/季节基准并拟合规则天气反应。所有参数在此冻结。
- 9月22–30日：一次性留出检验，含多个降雨日和9月29日极端暴雨；其他雨日不都称为极端事件。
- 用实测当小时天气和截至当小时的过去6小时累计降水。因此是已知天气条件的历史预测，不是提前获得天气预报的部署试验。
- LLM不接收站名、真实日期、测试客流或纽约暴雨新闻，以减少事件记忆泄漏；仍不能证明预训练完全不知道相关事件。

## 相同基准与四类预测

每站小时先建立总需求，再按票种分配。学生票、Fair Fare、老人及残障合并标签、其他票种四组；缺失票种仅在分配质量时暂作零贡献，评分保留原始缺失。源数据无法拆开老人和残障乘客，不能声称分别验证。

1. 八月基准：未校正开学的敏感性对照。
2. 季节基准：使用9月前段干天气校正，不使用LLM。
3. 天气规则：每组拟合降水指数衰减，使用同一校正基准。此处是实验内对照，不替换协作者负责的rule_based_abm目录。
4. LLM直接：输出天气情境的整体需求乘数，无个体代理与记忆。
5. LLM ABM：Mesa中的持久群体代理，根据LLM策略选择继续地铁、推迟一小时、改方式、取消。

LLM直接与LLM ABM都比较zero/few，并各独立生成3次策略。LLM ABM另外比较5/10/20个代理。软件中的seed是重复样本编号及Mesa随机种子，API未提供可保证复现的采样种子；保存实际响应用于离线重放。

## 群体代理机制

每个代理代表一部分需求质量，不是实际一名乘客。每站建立5/10/20个代理，12站合计60/120/240。每一票种组权重之和恒为1，增加代理不会增加乘客总量。假设的出发灵活度采用均匀分布中点，所有分辨率平均灵活度均为0.5；这是假设人口表示，不是来源个人属性。

策略按4种天气×peak/offpeak共8个情境输出四项概率。dry=正常计划出发；light=少量当前/近期雨；moderate=当小时≥5mm或6小时≥10mm；extreme=6小时≥30mm。peak为工作日7–9及16–19点。API中数值是各类别的固定代表情境，并非逐小时直接请求，因此同一类别内天气细节不会改变LLM策略。

Mesa逐小时维护每个代理的推迟需求；默认60%于下一小时返回，并免费重放0%与100%的敏感性试验。推迟需求遇时间缺口清零。改方式和取消都离开当前地铁需求；未模拟真实目的地、换站、线路拥堵或同伴互动。模型使用概率期望值，不逐个抽样数百万乘客。代理共享天气输入，但没有学习闭环或社会传播。

## 提示与API预算

Pro: `doubao-seed-2-1-pro-260915`，关闭thinking，temperature0.7。zero只给任务、群体设定和天气；few额外给8月聚合客流/基准比例，并明确它们不是个人行为或因果效应。两种方式、三个代理数量使用同一基准和样例。

策略请求为每个配置/重复一次，跨12站和全部检验小时复用。预计主实验24次策略请求（18次ABM、6次direct），加小规模预检；上限200,000个API报告token，逐次记账并预留最大输出。保存请求、原始响应、使用量、策略和版本，失败不冒充真实API响应、不用聊天文本补造结果。

## 评分与图表

主要评分：12站所有留出小时的总客流WAPE，辅以MAE、RMSE、偏差。汇总真实站点总客流独立于票种缺失；群体评分仅在该组有源记录时计算。另展示雨情境、9月29日小时过程、各组误差、站点地理分布、代理数与推迟返回率敏感性。

报告重复运行的均值与范围，但3次策略重复不是3次独立暴雨事件，也不能代表城市泛化置信区间。12站与一个确认极端事件只能支持本案例探索。模型组可以沿相同输入与输出格式接入后续独立规则模型。

## 结果解释时的额外边界

LLM离线生成固定策略，运行时Mesa执行概率期望；这属于LLM生成策略的群体ABM，不是每小时在线调用LLM或持续学习。策略在所有站点共享，LLM不看到站点特征；地理误差差异来自站点基准与票种组合，不能解读为LLM学到了空间异质性。

干天策略由程序强制正常出发，因此不能把干天行为合理称为LLM自发验证结果。direct可以直接增加需求倍率，ABM当期新增计划需求只会削减（推迟回流可抬高之后的某小时），两者可行域不同。代理数比较同时包含人口分布离散近似和新的策略生成噪声，不能把所有差异都归因于规模本身。

数据准备后的情境覆盖检查：8月有637个dry、92个light、15个moderate小时，无extreme；校准期有442/54/8/0小时；测试期有97/89/11/19小时。few-shot因此只有4种湿天气/peak组合、每组一条聚合示例，共16条，没有极端情境示例。极端情境是训练和校准范围外的外推检验，不把测试极端数据补进提示。
