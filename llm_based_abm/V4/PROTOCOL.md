# V4 实验约定

比较七种方法：过去四个同星期小时中位数 baseline、Ridge 数值模型、规则 Mesa ABM，以及 Lite 的直接预测/画像决策 × zero-shot/few-shot。

- 选站只看 2023 年 7 月：每行政区选两个客流三分位附近、小时覆盖 ≥98% 的站，共 8 站。
- July 为训练；Aug4–7 为验证；8–10 月共 24 个预先固定测试日，详见 res/design.json。测试日包括 Aug13、Sep29、Oct7 三个强降雨日；不根据预测误差选日期或模型。
- 强降雨是本研究操作定义：当天最大小时雨量 ≥10mm，或最大过去六小时雨量 ≥30mm。不是官方气象事件等级。JFK 单站天气无法刻画每个地铁站的局地降雨。
- 各架构使用同一数据来源：数值/直接路线读取历史客流；角色路线由外部执行器使用历史机会量，人物本身只看到画像与自己的合成记忆。各路线均使用实测目标天气。日历只提供星期，隐藏站名、具体日期及当前真实客流。任务是天气已知的回顾性预测，不是提前一天使用真实天气预报的部署效果。
- 计划量只用过去 7/14/21/28 天同小时的中位数，缺失时退回 July 星期/小时均值。群体权重也从历史票种建立，原始缺失不当零评分。
- 每站 8 个合成代表，四票种各 2 人，每组覆盖一个固定/必须出行人物和一个灵活人物；老人及移动支持需求者作为两个独立合成身份，但真实票种标签仍合并，不能拆开评分。职业、预算、性格和目的是假设，不是人口调查记录。
- 一个 API 请求只扮演一个人，给出同一次计划出行在六种可能出发时段下的行动。不是一人每天出行六次，也不让 LLM 预测群体总数。每个代表的策略作用于该群体历史小时分布，按组内权重汇总，避免少数代表的出发时刻离散造成小时误差。
- 行动：地铁、推迟 60/120 分钟坐地铁、公交、出租、步行、远程、取消。菜单、预算、必须到场和延迟上限由 Python 约束。API 采用独立的 subway / delay_subway_60 / delay_subway_120 行动标签，Python 按标签无损转成标准 action + delay_min。选择会改变流量及到站时刻；跨午夜流量单独记账。测试日是抽样独立流量预测，未模拟缺失日期的入站延迟回流。
- 计划群体量为零的代表不调用 API、不更新记忆，记录为 not_applicable；它表示模型内没有计划机会，不证明现实没有该群体乘客。角色保留前三次自己的模拟策略经历，天气额外耗时是假设，不用真实测试误差更新人物。测试开始重置验证期记忆；抽样日期之间不捏造个人真实经历。不同站点子集不改变同一人物的固定属性。
- 直接 few-shot：三个最相近、24 小时有观测的 July 训练日期，以天气和星期选例，示范输入及真实汇总输出；直接 zero-shot 也能看到过去客流，但没有输入/输出示范。
- 角色 few-shot：两条该人可执行的、由规则生成的合成行动示范。没有真实个人行动标签，不能称“根据真实人的选择学习”。Zero/few 比较的是这些示范的效果；两条路线的示例来源不同。
- 规则只在验证期选 rain_scale；Ridge 在 July15–31 训练，alpha 只在验证期选。另报告各方法在同一验证期拟合的单一总量校正系数，原始结果仍是主要结果。测试后不调提示、画像或参数。
- 主指标为共同有观测小时的站点日总 WAPE；辅以四小时/小时 WAPE、偏差、按月、天气类别、单个极端日、站点及规则/角色票种误差。缺失小时不补零。Bootstrap 按日期成组重采样，不把同一天 8 站当作 8 次独立天气事件；极端日只有 3 个，主要逐事件展示。
- 新维度只用于第二组回顾性对照：ACS 年龄/在校/残障行政区比例、当前线路连接及 ADA 编码。ACS 2023 五年估计在 2023 年后发布，当前路网/ADA 来自 2026，不能放进严格的 2023 时间可用主实验。没有 tract 服务区边界，人口特征是行政区居民比例，不是乘客比例。
- Sep29 服务记录只用于事后运营背景检查，不能把当天的实际列车观测提前告诉模型，也不能从缺失班次推断停运。
- 额外固定探针：两个站 Aug13/Sep29/Oct7/Oct13，增加代表人数、重复采样及有/无补充维度。子集对照共用输入和初始化，不按误差挑人数。它们不混入主结果。

仅用 `doubao-seed-2-1-lite-260915`，关闭深度思考，temperature=.3，最多 650 输出 token。默认总预算 5,000,000；只有完成上述额外对照需要时才增加，绝不超过用户允许的 10,000,000。正式测试前的接口排错及画像覆盖修正也保留并计入预算；原始响应、输入、usage、失败与修复均记录；无 usage 的失败保守记账。缓存复用，禁止手填 LLM 结果或用规则补失败后冒充 LLM。

依据：交通 LLM-ABM 应同时检查个体约束和系统指标，而不是只展示可信的理由：[Liu et al., 2025](https://arxiv.org/abs/2503.22718)。人物记忆参考 [Generative Agents](https://arxiv.org/abs/2304.03442)，但本项目没有个体访谈，不能宣称复现真实人：[Park et al.](https://arxiv.org/abs/2411.10109)。用户 Zotero 中的 [Wu et al., 2020](https://doi.org/10.1126/sciadv.abd4049) 支持警惕从地区汇总推断个人。仅核对所选文献摘要，不声称完成全文综述。Census 字段按官方 [B01001](https://api.census.gov/data/2023/acs/acs5/groups/B01001.html)、[B14001](https://api.census.gov/data/2023/acs/acs5/groups/B14001.html)、[B18101](https://api.census.gov/data/2023/acs/acs5/groups/B18101.html) 定义计算；没有把不同人口分母混为一个群体比例。
